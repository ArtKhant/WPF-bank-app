# Management App

A small project implementing a bank managment application. 

Written in 2024.

---
  
## User can log in as consultant or manmager. User can enter as manager if them enter a password. Manager has more permitions, rather than consultant. 
 - **Consultant** can change phone number of client and transfer money between clients bank accounts or to  account of other client. Consultand can't see passport information of a client.
 - **Manager** can change all information of a client and change it. Also **Manager** can add clients into system.
