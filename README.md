# Bank App (WPF)
 
A small project implementing a bank management application.
 
Written in 2024.
 
---
 
## Roles & Permissions
 
Users can log in as either a **Consultant** or a **Manager**. Logging in as a manager requires entering a password. Managers have broader permissions than consultants.
 
- **Consultant** — can change a client's phone number and transfer money between bank accounts (including to accounts belonging to other clients). Consultants cannot view a client's passport information.
- **Manager** — can view and edit all client information, and can add new clients to the system.
